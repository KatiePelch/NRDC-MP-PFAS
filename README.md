# Structure

  - data/
    - contains the datasets
  - out/
    - all produced outputs, including preprocessed data and model objects

**File types**

  - .R: R script
  - .Rproj: R project file
  - .qmd: Quarto file (markdown)
  

# File descriptions

**Appendix**

  - model_details
    - A written description containing detailed information about the 
    modelling and analysis.

**Analysis files**

  - preprocess.R
    - Various preprocessing steps to prepare data for analysis.
  - plots_mp
    - Exploratory plots for microplastics.
  - plots_pfas
    - Exploratory plots for PFAS.
  - models_evaluate
    - Fit all models, and run model diagnostics.
  - output_mp
    - The main results for microplastics, including all results cited in manuscript.
  - output_pfas
    - The main results for PFAS, including all results cited in manuscript.
    
**Other files**

  - LICENSE.md
    - CC-BY-4.0 license
  - refs.bib
    - References bibtex file.
  - vancouver-brackets.csl
    - File for formatting references in Vancouver style.
